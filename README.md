# Ai-based-product-recognition-tool
link- https://teachablemachine.withgoogle.com/models/eIv523c9P/

A no-code AI model built using Google Teachable Machine that recognizes and classifies products into predefined categories using images captured through a live camera feed or uploaded photographs.
The model can support retail automation by identifying products and enabling applications such as:
Smart checkout: Assist in identifying products during billing.
Inventory tracking: Help recognize and categorize products.
Retail shelf monitoring: Support product identification and shelf management.
Technology used: Machine learning, computer vision, image classification, Google Teachable Machine.
